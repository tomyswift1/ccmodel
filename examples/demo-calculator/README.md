# Calculator Demo Project

A tiny dependency-free Python project used to demonstrate the coding agent.

## Requirements

- `add(a, b)` returns the sum of two numbers.
- `subtract(a, b)` returns `a - b`.
- `divide(a, b)` returns `a / b` for a non-zero divisor.
- When `b == 0`, `divide(a, b)` must raise `ValueError("division by zero")`.

Run all tests with:

```bash
python -m unittest -v
```
